Projects
Text-Based Dungeon Game

Dungeon crawler video game where one must use text-based inputs to navigate a dungeon. Players will use items and weapons they find throughout the dungeon to assist them in their adventures.

Wordle Recreation

Recreated the NYC Times game Wordle in Python. The program can choose from a list of pre-registered words that the player can guess. Game functions fundamentally the same as Wordle, where players guess words and are given hints depending on how close they are.

Side Scrolling 2D Platformer Game

Simple 2D platformer video game made as practice for game development. Players must navigate from area to area collecting items to complete each level.
Final Project Idea

Following the trend of some of my previous projects, I believe it would be fun to make an in-browser video game. To be more specific, a game where the player controls a character that must avoid objects and projectiles in order to gain a higher score. The player will be able to freely control the character in a two-dimensional space.
